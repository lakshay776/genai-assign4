Assignment 04 - Website Automation Agent 
Assignment Overview 
Create an intelligent website automation agent capable of interacting with web pages 
autonomously. This project serves as a mini-version of browser automation tools like Browser 
Use, demonstrating your understanding of AI-driven browser control and web automation. 
Project Objective 
Build an automation agent that can navigate to a specific URL, interact with web elements, and 
perform form-filling operations without manual intervention. Your agent should demonstrate 
intelligent decision-making in identifying and manipulating web page elements.
